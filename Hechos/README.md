## Descripción
Este proyecto representa una base de conocimiento sobre clasificacion de animales utilizando diccionarios, tuplas y predicados en Python.

La informacion fue obtenida a partir de la actividad de adquisicion de conocimiento, incluyendo el analisis de las notas de la biologa Ana Torres y las entrevistas realizadas sobre el leon marino y el pato.

## Archivos del proyecto

### hechos_animales.py

Contiene:
- Diccionario `universo` con las clases y caracteristicas de los animales.
- Tuplas `hechos` para representar hechos en formato `(sujeto, relacion, objeto)`.
- Predicados para realizar consultas.
- Consultas de prueba con resultados verdaderos y falsos.

### ontologia.md
Contiene:
- Clases
- Instancias
- Propiedades
- Relaciones
- Axiomas
- Diagrama de la ontologia
